# ScreenPath

A free screen-reader fluency practice resource created by Moises Betancourt for students and teachers of students with visual impairments.

## Pilot scope

The School contains three rooms: The School Office (headings and tables), The Library (links and tables), and The Computer Lab (form navigation). Learners can choose untimed Practice or a timed Challenge with a 1–60 minute allowance.

This repository contains the featured website only. Additional activities remain development drafts.

## Use the website

Open the published GitHub Pages link. Students do not need GitHub accounts. Review the teacher guide before classroom use.

## Results and privacy

No student account or name is required. Completed-room results and optional reflections are saved in the browser on the device being used. They do not sync between devices. Email Results opens an email draft; nothing is sent automatically. Copy Results copies text for the learner to share. Avoid personal information in optional notes. Clearing browser data removes saved results. People sharing a browser can see its saved results.

The hosting provider handles web requests under its own privacy terms. Some activity images are loaded from Unsplash.

## Accessibility status

The pilot has automated logic and accessibility-structure checks. All 18 randomized School tasks were tested in an isolated DOM. These checks do not establish compatibility with every browser, device, or screen reader. Visual and hands-on assistive-technology testing remain necessary, starting with Mac and VoiceOver.

## Publish with GitHub Pages

1. Keep index.html and the other website files at the repository root.
2. In Settings → Pages, select Deploy from a branch.
3. Choose the main branch and /(root), then save.
4. Wait for deployment and open the link shown by GitHub Pages.

No build command or extra dependencies are needed. The .nojekyll file keeps the website as plain static files.

## Update the pilot

Keep the HTML, CSS, and JavaScript files together. Test the School activity before publishing changes. Do not add student records, backups, or private project documents to this public repository.

## Feedback
