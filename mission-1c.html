Room 3 of 3 — Locked In

The Computer Lab

Where You Are

This is a fictional practice activity. No real emergency message is sent.

Both codes worked. The corridor keypad accepted the access code from the office and the terminal accepted the library code. A message appeared on the screen telling you one more step was needed. To complete the emergency exit authorization the after-hours alert system needs to verify your identity as a registered student.

You followed the corridor to the computer lab. Every monitor in the room is dark except one at the far end. You sit down. The screen shows a form connected to the school's after-hours emergency alert system. This system was designed exactly for situations like this. When a student is accidentally locked inside after hours, submitting this form sends an automated alert directly to the principal's cell phone and district security. No one needs to be watching a screen. The system handles it automatically.
